# Navigator AI - RAG Trading System

Sistema de consulta RAG inteligente para el Plan de Trading utilizando Streamlit, LangChain, FAISS y Google Gemini API.

## Estructura del proyecto
- `app.py`: Interfaz de usuario con Streamlit.
- `rag.py`: Lógica de recuperación y generación con LangChain y FAISS.
- `config.py`: Variables de entorno y configuración general.
- `plan_trading_navigator.pdf`: Documento base de conocimiento.
